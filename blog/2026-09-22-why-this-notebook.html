A small worked example

As a test of the machinery: the layers in a binary neural network replace full-precision weights $w \in \mathbb{R}$ with a single sign bit, using something close to

$$ w_b = \operatorname{sign}(w) = \begin{cases} +1 & w \geq 0 \\ -1 & w < 0 \end{cases} $$

which turns a multiply-accumulate over $n$ weights into a handful of XNOR and popcount operations — the entire reason a BNN layer can run on a microcontroller that would choke on a full floating-point network. A minimal version of the packed dot product looks like this in C: 

// dot product of two {-1,+1} vectors packed as bits,
// via XNOR + popcount instead of n multiplies and adds
int32_t bnn_dot(uint32_t a, uint32_t b, int n) {
    uint32_t agree = ~(a ^ b);           // 1 where bits match
    int ones = __builtin_popcount(agree & ((1u << n) - 1));
    return 2 * ones - n;                 // map {0..n} bit-count back to {-n..n}
}

If both the display equation above and the code block rendered the way you'd expect, the notebook works. Everything after this post is content, not plumbing.
