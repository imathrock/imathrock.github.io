## Memory alignment
Memory in RISC V is aligned according to either the byte, halfword, word or doubleword. halfword is divisible by 2, word is by 4 and doubleword is by 8.

All instructions must be halfword aligned, since compressed instructions and full instructions can be intertwined so they must be halfword aligned. 

For load store of halfword and word, the alignment of the memory is implementation dependent. If they are not aligned then an exception can occur, causing a trap handler to run and terminate and report or align it, handle it and return. Or just let undefined behaviour happen, not advisable.
