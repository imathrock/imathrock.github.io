Projects

Mostly C, mostly things that touch either hardware or a training loop. Source for everything is on GitHub.

RISC-V Processor with Vector GEMM (in progress)

verilogfpgarisc-vgemm

An RV32I processor written in Verilog for a DE1-SoC FPGA: first a sequential core, then a 5-stage pipeline, then a vector extension subset with a GEMM kernel that uses the FPGA's DSP blocks. Documented day by day in the build log.

Gesture-Controlled RC Vehicle

cembeddedmsp430i2crf

Capstone project for UBC PHYS 319. A gesture-controlled vehicle built on an MSP430 with an MPU6050 IMU (custom I2C driver) and an nRF24L01 link carrying gesture data to the car in real time. The firmware interprets motion and runs a signal-filtering pipeline for smooth control.

github.com/imathrock/Gesture_Control_RC

LC-3 Virtual Machine and Assembler

cc++systemsvirtual-machine

A complete virtual machine for the Little Computer 3 (LC-3) and a two-pass assembler, both written in C. Implements the full instruction set, trap routines, memory-mapped I/O, and precise symbol resolution with a static listing table. Example programs (Hello World, 2048) run on the VM, and the assembler was tested by compiling many different LC-3 programs.

github.com/imathrock/LC3-VM

Sphericat: Quantum Mechanics Solver

c++openglfortrannumerical-methods

A multi-dimensional Schrödinger equation solver in object-oriented C++, using finite-difference and Crank-Nicolson methods to simulate quantum mechanical systems. Memory footprint for large sparse Hamiltonians is kept down with optimized GEMM libraries and Arnoldi/Lanczos eigenvalue algorithms.

High-Performance CNN Framework

cavxpthreadsneural-networks

A zero-dependency convolutional neural network framework in C. AVX (SIMD) vectorization, pthreads, and cache-aware memory handling speed up the matrix operations by about 8x. Reaches roughly 96% accuracy on MNIST and 90% on Fashion-MNIST.

github.com/imathrock/CNNs-in-C

Instrument Control Library

pythongpibrs232daq

A Python control library over RS232/GPIB that automates lock-in amplifiers, oscilloscopes, and DMMs. Strict DAQ timing protocols reduced measurement uncertainty by 80% in High-Tc experiments.

FPGA Emulator (incomplete)

cfpgadigital-logic

A software emulator for configurable logic blocks, built to understand FPGA internals from the logic-cell level up, using Logisim for circuit design with an eye toward eventual Verilog-to-circuit translation.

github.com/imathrock/FPGA-emulator
