Projects

Mostly C, mostly things that touch either hardware or a training loop. Source for everything is on GitHub.

Framework for CNNs in C

cneural-networkssimd

A framework for building convolutional neural networks from scratch in C, with numpy-style SIMD vectorization. Reaches roughly 96% accuracy on MNIST and 90% on Fashion-MNIST with no dependencies beyond the standard library and a vector intrinsics header.

github.com/imathrock/CNNs-in-C

Gesture Control RC Car

cembeddedi2crf

Capstone project for UBC PHYS 319. A gesture-controlled RC car built around a custom I2C driver for an MPU6050 accelerometer/gyroscope, with an NRF24 link carrying gesture data to the car in real time.

github.com/imathrock/Gesture_Control_RC

LC-3 Virtual Machine

csystemsvirtual-machine

A from-scratch virtual machine for the Little Computer 3 (LC-3) instruction set: 10 registers, the full 16-bit instruction set, memory mapping, and I/O handling, with example programs (Hello World, 2048) running on top of it. An LC-3 assembler is in progress.

github.com/imathrock/LC3-VM

FPGA Emulator (incomplete)

cfpgadigital-logic

A software emulator for configurable logic blocks, built to understand FPGA internals from the logic-cell level up, using Logisim for circuit design with an eye toward eventual Verilog-to-circuit translation.

github.com/imathrock/FPGA-emulator

PyTorch exercises

pythonpytorchcomputer-vision

A collection of smaller PyTorch projects — rice-grain classification, animal image classification, training GoogLeNet from scratch — used to build up fluency with the framework and with training loops in general.

github.com/imathrock/simple-PyTorch-Projects
