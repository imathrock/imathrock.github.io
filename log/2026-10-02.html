Reading more about ISA and refreshing verilog

2026-10-02 · Log #6 · risc-visa ·

I'm watching this series

A detail to remember about the ISA is that destination registers come first in an instruction, as we saw they are represented by bits 7 to 11. But the store instructions have the destination address last.

Arithmatic and logic instructions

These are how the logic instructions function 

add     rd, rs1, rs2    # rd = rs1 + rs2, register to register
addi    rd, rs1, imm12  # rd = rs1 + imm12, add immediate, number is signed, range is limited to +/- 2k.
# same for subtract

The difference between normal add and add immediate is in the opcode, one single bit is different, differentiating them.

Here is the list of all Arithmatic and Logic instructions: 

add     rd,rs1,rs2  # rd = rs1 + rs2
sub     rd,rs1,rs2  # rd = rs1 - rs2
and     rd,rs1,rs2  # rd = rs1 & rs2
or      rd,rs1,rs2  # rd = rs1 | rs2
xor     rd,rs1,rs2  # rd = rs1 ^ rs2
sll     rd,rs1,rs2  # rd = rs1 << rs2
srl     rd,rs1,rs2  # rd = rs1 >> rs2
sra     rd,rs1,rs2  # rd = rs1 >>> rs2
slt     rd,rs1,rs2  # rd = (rs1 < rs2) ? 1 : 0
sltu    rd,rs1,rs2  # rd = (rs1 <u rs2) ? 1 : 0
  • sll is shift left logical, srl is shift right logical, put zeros in the vacated bits.
  • sra is shift right arithmatic, where signed bit is extended instead of zeros.
  • slt is set less than, sets rd to be 1 or zero if rs1 less than rs2. sltu is same but for unsigned.

It's the same for AL immediate. The second operand is replaced by the imm12 value and the name gets an i at the end, the only difference is that the sub instruction is not available, if you want to subtract just negate the immediate value.

Load and store instructions

The following are the load instructions: 

lb  rd,imm(rs1)     # rd = mem[rs1+imm12], loads byte       , sign extended
lh  rd,imm(rs1)     # rd = mem[rs1+imm12], loads halfword   , sign extended
lw  rd,imm(rs1)     # rd = mem[rs1+imm12], loads word (4 bytes in our case)
lbu rd,imm(rs1)     # rd = mem[rs1+imm12], loads byte       , unsigned
lhu rd,imm(rs1)     # rd = mem[rs1+imm12], loads halfword   , unsigned
sb  rs2, imm12(rs1) # mem(rsi+imm12) = rs2
sh  rs2, imm12(rs1) # mem(rsi+imm12) = rs2
sw  rs2, imm12(rs1) # mem(rsi+imm12) = rs2
