HDL practice

2026-10-05 · Log #8 · risc-visa ·

Today it was as though I never knew verilog. I guess it's true, if you don't use it you lose it. So I'm practicing and learning verilog today. I'm practicing on HDLbits, which is like leetcode for HDL.

I breezed thru the getting started section, because it's the basics obviously. There are 3 ways of going about writing verilog, one is describe circuit, then describe logic and then describe behaviour. I mostly used the logic way of writing and did about 28 questions. I quite enjoyed doing them. My rank is 47863 at the end of the day.

I'm genuinely enjoying this stuff but next up comes the paper computer. Idea is that I create an outline of the CPU on paper to get an idea of how to go about programming the FPGA. After that I would make a plan and start writing verilog for the CPU. Sequential to begin with.
