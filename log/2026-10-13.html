A stopwatch on FPGA

2026-10-13 · Log #11 · Verilog ·

Today I decided let's do something on the FPGA. So to begin with I started by making a simple counter. I did not take a video of the counter but it was that according to the clock it would count till 1024 in binary using the leds above the switches. Then I made one small change and now instead of the clock it was running on a push button.

I then realized that I need to be able to reset this, so I added a reset wire and hooked it up. It was based on a simple if condition in an always block. It only triggerred with I held it down and clocked manually, which means I implemented a synchronus reset. To implement the async reset I put another clause in the always block where the counter would reset based on the negative edge of the reset and voila it reset when reset was clicked regardless of what clock was doing.

I then went on to attempt the 7 segment display. To translate from binary to hex I needed to write a new module that took a wire array as input and it then outputs the necessary numbers. I then created a binary coded decimal counter and I got the 7 segment display working, it counted till 0xF. I then extended it to another display. I then saw that both the counters were incrementing simultaneously. I then realized that I needed to link 2 different bcds together such that the second would count every 10 counts of the first. I used an enable input and a carry output. The enable for the first case is set to 1 always and for the subsequent counters it's enabled once the number reaches max. The carry of the current counter is the enable for the next. I then hooked these up to a clock and slowed the clock down to 10ths if a millisecond and I had a working stopwatch.

To add the stop reset functionality I added a simple latch that stopped and started the counter's enable based on the latch's state.

The code's been uploaded to git.
